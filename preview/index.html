5 · 安全区校验

图形实际占位 x 22.5 → 84.5、y 37 → 71，全部落在虚线安全区 （圆心 54,54，半径 33dp）之内。四个角的极值到圆心距离分别是 31.5 / 30.5 / 17.1 / 24.0，都小于 33。任何启动器的裁切蒙版都不会切到图形。

6 · 位图渲染校验 用 libvips 把同一套路径参数渲染成位图后逐条核对

上排是 160 / 96 / 64 / 48 / 32 / 24 六种尺寸， 下排左是修复后的图标，右是修掉之前的旧写法（波形没写 fillColor）。

  • 大、中尺寸圆点与波形清晰可辨，最小尺寸下开始挤在一起但仍可分辨
  • 所有尺寸图形都完整落在圆内，四周留有一圈蓝色空隙，无裁切
  • 圆点与波形间距偏近，读作一个整体，没有分离感
  • 波形是平滑曲线，波峰波谷基本对称，图形水平垂直居中

右边那张能看到波峰下方一块黑色楔形、波谷处一条横向黑带， 黑色约占波形区域的 1/4 ~ 1/3。这就是原图标里一直被白色描边盖住、 没被察觉的黑色填充 —— 也是这张对比图能画出来的前提。

改动清单

  • 前景 drawable/ic_launcher_foreground.xml — 圆点 + 平滑正弦两拍，两个元素。笔宽 7、圆头圆角。波形用 Q/T 画平滑曲线，不是折线
  • 修掉一个遗留缺陷 — VectorDrawable 的 <path> 不写 fillColor 时默认取 Paint 缺省的黑色，原图标只写了 strokeColor，折线下方一直压着一层黑色填充。新波形显式写 #00000000
  • 背景 values/ic_launcher_background.xml — #3482FF，单一纯色，这是 Android 12+ 莫奈重染的前提
  • 自适应图标 mipmap-anydpi-v26/ic_launcher.xml — 保留 <monochrome> 层，Android 13+ 主题化图标靠它生效
