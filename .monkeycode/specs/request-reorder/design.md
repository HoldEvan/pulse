# 请求排序

Feature Name: request-reorder
Updated: 2026-10-23

## 设计

集合一直用扁平列表作为唯一数据源，同一文件夹的展示顺序就是条目在列表里的相对顺序，因此不需要新增排序字段：上移/下移只是与「同文件夹的相邻条目」交换位置，置顶则把条目移到该文件夹第一条之前。

`CollectionStore.moveRequest(id, offset)` 先筛出同文件夹条目的下标序列，定位当前条目的位次，越界直接返回 false（不落盘）；交换用 `MutableList` 的两次赋值完成。`pinRequest(id)` 取同文件夹的首个下标，用 `removeAt + add` 把条目搬到该位置。两者都只影响同文件夹条目，其他文件夹的相对顺序不变。

界面在接口行菜单顶部新增「置顶 / 上移 / 下移」，用 `DropdownItem.enabled` 在首位/末位时置灰，避免点击无效操作。

## 验证

单测覆盖：上下移交换、边界返回 false 且不落盘、置顶只影响本文件夹、首位置顶无操作（4 项）。手工验证三语菜单与重启后的顺序。全量单测 358 项与 Release 构建。
